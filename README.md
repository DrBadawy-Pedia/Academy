# Dr Badawy Academy

This is the starter GitHub Pages structure for **Dr Badawy Academy**.

## Structure

- `index.html` — Academy homepage
- `topics/diabetes-dka.html` — first interactive Pediatrics topic
- `assets/` — future shared images, logos and files

## First topic

Diabetes Mellitus & DKA in Pediatrics.

## Next steps

1. Upload this folder to a GitHub repository.
2. Turn on GitHub Pages.
3. Open the generated Pages URL.
4. Add more topic files into `topics/`.
5. Add each new topic to `index.html`.

This is intentionally a simple starter structure so the Academy can grow without rebuilding everything.
